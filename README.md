# zerobear OS

Codex·Claude Code용 공통 지침과 스킬을 관리하는 개인 AI 개발 환경.

## 설치

Python 3.9 이상. 저장소 폴더에서 실행.

```sh
python install.py
```

지침·스킬·세션 기록 훅 설치. 기존 지침·스킬은 백업 후 교체. 기존 Claude 기록 Stop 훅은 백업 없이 교체하며 다른 훅은 유지. `python`이 없으면 `python3` 사용.

설치 후 새 대화 시작. Codex는 `/hooks`에서 새 훅 신뢰 확인 필요. 세션 기록은 로컬 Codex·Claude Code용.

## 사용

새 대화에서 스킬 이름과 대상 지정. 예: `simple-code로 이 메서드를 리팩토링해줘.`

| 스킬 | 역할 |
| --- | --- |
| `simple-word` | 쉬운 기술 설명 |
| `bug-debug` | 이슈·로그 분석 전용 |
| `code-review` | 코드 리뷰 전용 |
| `simple-code` | 구조·동작을 유지하는 최소 수정 리팩토링 |
| `session-close` | 종료 의도 판단 후 세션 요약 저장 |

스킬 원본 수정은 연결에 반영. 지침 수정·스킬 추가·폴더 이동 시 재설치.

“오늘은 여기까지 하자”처럼 요청하면 세션 기록. 최초 요청 시 저장 폴더 지정, 없으면 생성 여부 확인. Obsidian 앱 없이도 Markdown 저장. 작업 요약 제목·날짜 메타데이터·토큰 K/M 표시, 비용 제외. 같은 세션은 같은 노트 갱신. 앱·터미널 자동 종료 없음.

## 제거

```sh
python uninstall.py
```

설치 기록과 일치하는 항목만 제거. 원본·사용자 수정·백업 보존. 백업 자동 복원 없음.
