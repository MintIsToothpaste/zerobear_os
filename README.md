# zerobear OS

Codex·Claude Code용 공통 지침과 스킬을 관리하는 개인 AI 개발 환경.

## 설치

Python 3.9 이상. 저장소 폴더에서 실행.

```sh
python install.py
```

지침·스킬·세션 기록 훅 설치. 기존 지침·스킬은 백업 후 교체. 기존 Claude 기록 Stop 훅은 백업 없이 교체하며 다른 훅은 유지. `python`이 없으면 `python3` 사용.

설치 후 새 대화 시작. Codex는 `/hooks`에서 새 훅 신뢰 확인 필요. 세션 기록은 로컬 Codex·Claude Code용.

## 사용

새 대화에서 스킬 이름과 대상 지정. 예: `simple-code로 이 메서드를 리팩토링해줘.`

| 스킬 | 역할 |
| --- | --- |
| `simple-word` | 쉬운 기술 설명 |
| `jira` | Jira 티켓·첨부 ZIP 로그 분석 전용 |
| `code-review` | 코드 리뷰 전용 |
| `simple-code` | 구조·동작을 유지하는 최소 수정 리팩토링 |
| `session-close` | 종료 의도 판단 후 세션 요약 저장 |

스킬·훅 코드 수정은 다음 실행에 반영. 지침 수정·스킬 추가·이름 변경·폴더 이동·훅 등록 설정 변경 시 재설치. 기존 `bug-debug` 연결은 설치 시 `jira`로 교체.

`jira로 RM3IS-2710 분석해줘.`처럼 티켓 번호로 사용. 설명·댓글·첨부 ZIP 로그와 현재 프로젝트 코드를 비교해 원인 분석. 최초 사용 시 Jira MCP 연결 확인, 미연결이면 주소 확인 후 설정·인증 안내. MCP 연결은 스킬 설치와 별도로 Codex·Claude Code 각각 설정. ZIP 다운로드는 연결 도구 지원 필요. 분석용 임시 파일은 정리하며 코드·Jira 변경 없음.

“오늘은 여기까지 하자”처럼 요청하면 세션 기록. 최초 요청 시 저장 폴더 지정, 없으면 생성 여부 확인. Obsidian 앱 없이도 Markdown 저장. 작업 요약 파일명, 속성에는 시작 날짜·토큰 K/M 표시. 비용·세션 ID·본문의 중복 제목과 토큰 제외. 같은 세션은 파일명을 유지하고 최신 요약으로 전체 갱신. 앱·터미널 자동 종료 없음.

## 제거

```sh
python uninstall.py
```

설치 기록과 일치하는 항목만 제거. 원본·사용자 수정·백업 보존. 백업 자동 복원 없음.
